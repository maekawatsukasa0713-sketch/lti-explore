## 本番開始前に残る必須確認
1. パスワード復旧: Supabase Authentication URL ConfigurationでSite URLとRedirect URLsを本番ドメインに合わせる。新しく発行したメール→MFA→8文字以上の変更→新パスワードでログインの実機確認。メールや認証コードをチャット/ログへ貼らない。カスタムSMTPと送信制限も確認。
2. バックアップ: DB（Auth・RLS・関数を含む）とStorageファイル本体を別途バックアップ。アクセスを限定した保存先と管理者を決める。DBバックアップだけではPDF/Word本体は戻らない。現在のプランはFreeであることを確認済み。課金変更は未実施。
3. 復元演習: 本番に書き戻さず隔離環境で復元。レコード件数・添付ファイル件数/チェックサム、PDF閲覧、学校間アクセス制限を確認する。
4. 実ログイン試験: テスト用の学校A/B、生徒/教員/運営の実セッションで課題・提出・フィードバック・公開申請・公開停止・仮パスワード発行を確認。今回はDB判定の隔離テストまで。
5. 監視・容量: AIの429/5xx・解析停滞、Auth送信失敗、Storage/DB容量、バックアップ失敗を監視する担当者と通知先を指定。通知の送信設定は未実施。
6. 漏洩パスワード保護は現在無効。利用可能なプラン/設定を確認して有効化する。秘密鍵の期限・ローテーションと運営アカウントMFAの復旧手順も確認。
